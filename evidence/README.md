# Evidence store

This directory holds immutable, domain-specific evidence files produced by a
pre-registered runner. Each file should identify:

- the preregistration fingerprint;
- dataset identifiers and hashes;
- the declared statistical method and all parameters;
- positive and negative control outcomes;
- p-value, effect size, and provenance of the execution.

Synthetic demonstrations must be labelled as synthetic and cannot be reported
as empirical TIMDR results.
